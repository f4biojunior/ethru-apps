# Backups do Grimório

Cópias do banco do Firebase (Firestore) feitas automaticamente nos dias 1 e 16 de cada mês.
Só os 2 backups mais recentes ficam guardados: este branch é recriado a cada backup, sem histórico.

Para restaurar: baixe o arquivo `.json`, abra o Grimório com a conta de administrador e use **Importar**.
